# KJ PARFUMS — Propuesta visual V2 (ETAPA 1)

Abra `index.html` en Chrome, Edge, Firefox o Safari. No necesita servidor para la navegación básica.

## Organización
- `index.html` — estructura HTML.
- `CSS/styles.css` — estilos y diseño responsive.
- `JS/app.js` — interacciones de demostración, catálogo y recursos multimedia.
- `IMG/logo-oficial.jpg` — logotipo oficial proporcionado (sin redibujar).

## Cómo incorporar contenido visual
Coloque archivos en `IMG/` **con estos nombres exactos**:

| Archivo | Ubicación en la web |
|---|---|
| `instagram-1.jpg` | Primera tarjeta de Instagram |
| `instagram-2.jpg` | Segunda tarjeta de Instagram |
| `instagram-3.jpg` | Tercera tarjeta de Instagram |
| `tiktok-1.mp4` | Primera tarjeta vertical de TikTok |
| `tiktok-2.mp4` | Segunda tarjeta vertical de TikTok |

Las imágenes se muestran automáticamente cuando los archivos están presentes. Los videos se reproducen sin sonido en bucle cuando el navegador lo permite. Las tarjetas mantienen sus enlaces al perfil oficial, **no a publicaciones específicas**. Para usar URL individuales, edite los atributos `href` de las tarjetas en `index.html`.

Recomendaciones: JPG optimizado y encuadre cuadrado para Instagram; MP4 H.264 vertical 9:16 para TikTok; archivos comprimidos para celulares. Para otros nombres o formatos, cambie la ruta en `index.html`.

Si no agrega medios, permanecen las ilustraciones editoriales de demostración del prototipo original. No se incluyeron fotografías ni videos extraídos de redes sociales porque no pudieron verificarse.

## Alcance y límites
Prototipo visual sujeto a aprobación. Los perfumes del catálogo son ficticios; los formularios no envían datos, no hay pagos ni WhatsApp conectado. No publica ni sincroniza automáticamente las cuentas. No inventa precios, stock ni cifras de popularidad.
